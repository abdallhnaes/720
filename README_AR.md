# ديربي كفردريان V10 - إخفاء تشكيلة الفريق الأول والثاني

## الجديد
- المدير الرئيسي يستطيع إخفاء تشكيلة الفريق الأول عن المستخدمين.
- مدير الفريق الثاني يستطيع إخفاء تشكيلة فريقه عن المستخدمين.
- المستخدم يرى تنبيه بدل التشكيلة المخفية.
- عند حفظ نتيجة مباراة، يتم حفظ حالة الإخفاء مع المباراة نفسها.
- بقيت صورة الفريق هي لوجو التطبيق.
- لا تظهر رموز الدخول التوضيحية داخل التطبيق.

## الصلاحيات
- المدير الرئيسي: يدير النظام كاملًا، الفريقين، الموعد، النتائج، وإخفاء تشكيلة الفريق الأول أو الثاني.
- مدير الفريق الثاني: يعدل فريقه فقط ويستطيع إخفاء تشكيلته.
- المستخدم: عرض فقط.
